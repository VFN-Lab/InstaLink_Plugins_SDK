InstaLink SDK

InstaLink SDK makes it straightforward for developers to build powerful browser extensions, AI/audio plugins, and native fullscreen games for the InstaLink Android browser.

Whether you want to modify web pages with JavaScript and CSS, call Android hardware capabilities like TTS, vibration, sensors, and notifications, or load high-speed compiled C++ adapters, InstaLink SDK handles discovery, sandboxing, and permission enforcement automatically.

Golden Rule: Extensions never communicate directly with Android OS APIs. All calls route through window.InstaLink into the permission-enforcing InstaLink Host.

Supported extension types

  • Web Extensions (runtime_mode: "web"): Content scripts, CSS injection, and local HTML settings UIs.
  • Hybrid & System Capability Extensions ("android" / "hybrid"): Invoke host TTS speech, notifications, device/network info, Bluetooth, volume, audio routing, sensors, and app launches.
  • Native C++ Adapters ("native"): Compile shared .so libraries loaded securely with dlopen/dlsym using include/instalink_extension_api.h.
  • Immersive Games: Fullscreen immersive_web canvas experiences or C++ ANativeWindow immersive_native games with built-in D-Pad overlays.

How it works

Extension UI / Content Script HTML + JS

Runs inside a sandboxed WebView (settings.html, index.js, styles.css, or web_canvas). It renders the extension interface and page scripts, without direct access to Android APIs.

Sends requests through the JS Bridge
window.InstaLink Bridge

The official JavaScript interface automatically injected by the browser, providing structured APIs: browser, storage, extension, capabilities, and nativeRuntime.

Verifies & dispatches securely to
InstaLink Host

The browser's security and validation engine. Every call is checked against the extension's declared permissions in manifest.json, user settings, and Android runtime permissions before execution.

Branches according to task type
Android OS & Hardware

Executes system capabilities safely on behalf of the extension: Notifications, TTS Speech, Sensors, Volume Control, Audio Routing, Vibration, Bluetooth, and App Launch.

Your Native C++ Adapter .so via C ABI

Loads your compiled .so library via dlopen/dlsym using instalink_extension_api.h to run AI/ONNX models, DSP audio, or ANativeWindow game rendering.

Get started & CLI

Scaffold, compile, and package a new InstaLink extension in under a minute using instalink-cli.

Prerequisites

  • Web extensions: Any editor + Python 3.8+ (for CLI packaging).
  • Native C++ / Game extensions: Android SDK with NDK (e.g. 27.0.12077973) and CMake (3.22.1).

CLI workflow

# 1. Create a new extension (--type: web | native | game)
instalink-cli.bat create my-extension --type web

# 2. Build native C++ adapters (Native / Game extensions only)
tools\build-native.bat .\my-extension

# 3. Package extension into dist/ (excludes native/ and build/ automatically)
instalink-cli.bat pack .\my-extension

Local NDK configuration (optional)

If your NDK lives outside %LOCALAPPDATA%\Android\Sdk, copy config.example.json to config.json and set ANDROID_NDK_HOME and CMAKE_PATH.

# Linux / macOS alternative
./instalink-cli.sh create my-extension --type web
./tools/build-native.sh ./my-extension
./tools/pack-extension.sh ./my-extension

JS Bridge, Permissions & Extension Examples

InstaLink automatically injects window.InstaLink into every extension page (settings.html), immersive web game, and matching content script. This single page covers the complete Bridge API, all permissions, Android runtime permission prompts, and ready-to-use extension examples for vibration, microphone recording, notifications, audio routing, sensors, Bluetooth, and app launching.

Initialization Rule: Always wait until window.InstaLink && window.InstaLink.__nativeReady is true and use window.InstaLinkActiveExtension as your fallback extension ID. 
(function waitForBridge(attempt) {
  if (!(window.InstaLink && window.InstaLink.__nativeReady)) {
    if ((attempt || 0) > 60) return console.error("InstaLink bridge unavailable");
    return setTimeout(function () { waitForBridge((attempt || 0) + 1); }, 80);
  }
  const extId = window.InstaLinkActiveExtension || "com.developer.smart_assistant";

1. Permissions Reference

Every capability in InstaLink follows a clear permission chain before execution:

  1. Manifest Declaration: Add the permission string to the "permissions" array in manifest.json.
  2. Browser Policy Check: Call window.InstaLink.extension.requestPermission(extId, perm) to verify the user allows this category in InstaLink Browser Settings (allow_device_capabilities, allow_sensitive_requests, allow_content_scripts, etc.).
  3. Android OS Runtime Prompt: Permissions backed by Android dangerous permissions (notifications on Android 13+, microphone, camera, location, connectivity_info for SSID, and bluetooth_info on Android 12+) must also be checked and requested with systemPermissionStatus() and requestSystemPermission().

Reusable Permission Verification Helper

Include this helper in every extension to verify both Browser Settings and Android OS runtime permissions cleanly before calling hardware features:

function ensureAccess(extId, permissionName, needsAndroidPrompt) {
  const allowedByBrowser = window.InstaLink.extension.requestPermission(extId, permissionName);
  if (!allowedByBrowser) {
    window.InstaLink.browser.toast("Enable permission in Browser Settings: " + permissionName);
    return { ok: false, reason: "blocked_by_browser_or_manifest" };
  }

  if (needsAndroidPrompt) {
    const status = window.InstaLink.extension.systemPermissionStatus(extId, permissionName);
    if (status.ok && status.requires_runtime_prompt) {
      window.InstaLink.extension.requestSystemPermission(extId, permissionName);
      return { ok: false, reason: "android_prompt_opened", missing: status.missing_permissions };
    }
  }
  return { ok: true };
}

4. Microphone Recorder & Audio Meter Extension (microphone)

To build a voice memo, sound meter, or voice-triggered extension, declare "microphone" in manifest.json. The user must allow sensitive requests in Browser Settings and grant Android's RECORD_AUDIO permission via requestSystemPermission(). Once granted, standard Web Audio and MediaRecorder APIs receive real microphone input.

let activeMicStream = null;
let mediaRecorder = null;
let audioChunks = [];

async function startMicrophoneRecorder(extId, onLevelUpdate, onClipSaved) {
  const access = ensureAccess(extId, "microphone", true);
  if (!access.ok) return access;

  try {
    activeMicStream = await navigator.mediaDevices.getUserMedia({ audio: true });

    // Haptic tap to confirm recording started
    window.InstaLink.capabilities.invoke(extId, "vibration", "vibrate", { duration_ms: 80 });

    // Live audio level meter using Web Audio AnalyserNode
    const audioCtx = new (window.AudioContext || window.webkitAudioContext)();
    const source = audioCtx.createMediaStreamSource(activeMicStream);
    const analyser = audioCtx.createAnalyser();
    analyser.fftSize = 256;
    source.connect(analyser);
    const bins = new Uint8Array(analyser.frequencyBinCount);

    function sampleVolume() {
      if (!activeMicStream) return;
      analyser.getByteFrequencyData(bins);
      let sum = 0;
      for (let i = 0; i < bins.length; i++) sum += bins[i];
      const levelPercent = Math.min(100, Math.round((sum / bins.length) * 1.4));
      if (onLevelUpdate) onLevelUpdate(levelPercent);
      requestAnimationFrame(sampleVolume);
    }
    sampleVolume();

    // Record audio clip with MediaRecorder
    audioChunks = [];
    mediaRecorder = new MediaRecorder(activeMicStream);
    mediaRecorder.ondataavailable = function (e) {
      if (e.data && e.data.size > 0) audioChunks.push(e.data);
    };
    mediaRecorder.onstop = function () {
      const blob = new Blob(audioChunks, { type: "audio/webm" });
      window.InstaLink.capabilities.notifications.show(extId, {
        id: 301,
        title: "Voice Memo Saved",
        body: "Recorded " + Math.round(blob.size / 1024) + " KB clip."
      });
      if (onClipSaved) onClipSaved(blob);
    };
    mediaRecorder.start();
    return { ok: true };
  } catch (err) {
    return { ok: false, error: String(err) };
  }
}

function stopMicrophoneRecorder(extId) {
  if (mediaRecorder && mediaRecorder.state !== "inactive") {
    mediaRecorder.stop();
  }
  if (activeMicStream) {
    activeMicStream.getTracks().forEach(function (track) { track.stop(); });
    activeMicStream = null;
  }
  window.InstaLink.capabilities.invoke(extId, "vibration", "vibrate", { duration_ms: 50 });
}

Inspect available physical sensors (list) and take real-time snapshots (snapshot) of Proximity, Ambient Light (lux), and Accelerometer ([x, y, z]). Requires "sensors" permission and allow_sensitive_requests enabled.

function checkEnvironmentSensors(extId) {
  const snap = window.InstaLink.capabilities.invoke(extId, "sensors", "snapshot", {});
  if (!snap.ok) return snap;

  const prox = snap.result.proximity;
  const light = snap.result.light;
  const accel = snap.result.accelerometer;

  const lux = light.available && light.values.length ? light.values[0] : null;
  const dist = prox.available && prox.values.length ? prox.values[0] : null;
  const xyz = accel.available && accel.values.length === 3 ? accel.values : [0, 0, 0];
  const gForce = Math.sqrt(xyz[0] * xyz[0] + xyz[1] * xyz[1] + xyz[2] * xyz[2]);

  if (lux !== null && lux < 15) {
    setVolumePercent(extId, 30); // Lower volume automatically in dark rooms
  }
  if (gForce > 15) {
    window.InstaLink.capabilities.invoke(extId, "vibration", "vibrate", { duration_ms: 120 });
    window.InstaLink.browser.toast("Shake detected!");
  }
  return { lux: lux, proximity: dist, gForce: Number(gForce.toFixed(2)) };
}

function ensureAccess(extId, permissionName, needsAndroidPrompt) {
  const allowedByBrowser = window.InstaLink.extension.requestPermission(extId, permissionName);
  if (!allowedByBrowser) {
    window.InstaLink.browser.toast("يرجى تفعيل الصلاحية من إعدادات المتصفح: " + permissionName);
    return { ok: false, reason: "blocked_by_browser_or_manifest" };
  }

  if (needsAndroidPrompt) {
    const status = window.InstaLink.extension.systemPermissionStatus(extId, permissionName);
    if (status.ok && status.requires_runtime_prompt) {
      window.InstaLink.extension.requestSystemPermission(extId, permissionName);
      return { ok: false, reason: "android_prompt_opened", missing: status.missing_permissions };
    }
  }
  return { ok: true };
}

      analyser.getByteFrequencyData(bins);
      let sum = 0;
      for (let i = 0; i < bins.length; i++) sum += bins[i];
      const levelPercent = Math.min(100, Math.round((sum / bins.length) * 1.4));
      if (onLevelUpdate) onLevelUpdate(levelPercent);
      requestAnimationFrame(sampleVolume);
    }
    sampleVolume();

    // تسجيل المقطع الصوتي عبر MediaRecorder
    audioChunks = [];
    mediaRecorder = new MediaRecorder(activeMicStream);
    mediaRecorder.ondataavailable = function (e) {
      if (e.data && e.data.size > 0) audioChunks.push(e.data);
    };
    mediaRecorder.onstop = function () {
      const blob = new Blob(audioChunks, { type: "audio/webm" });
      window.InstaLink.capabilities.notifications.show(extId, {
        id: 301,
        title: "تم حفظ التسجيل الصوتي",
        body: "حجم المقطع المسجل: " + Math.round(blob.size / 1024) + " كيلوبايت."
      });
      if (onClipSaved) onClipSaved(blob);
    };
    mediaRecorder.start();
    return { ok: true };
  } catch (err) {
    return { ok: false, error: String(err) };
  }
}

function stopMicrophoneRecorder(extId) {
  if (mediaRecorder && mediaRecorder.state !== "inactive") {
    mediaRecorder.stop();
  }
  if (activeMicStream) {
    activeMicStream.getTracks().forEach(function (track) { track.stop(); });
    activeMicStream = null;
  }
  window.InstaLink.capabilities.invoke(extId, "vibration", "vibrate", { duration_ms: 50 });
}

function checkEnvironmentSensors(extId) {
  const snap = window.InstaLink.capabilities.invoke(extId, "sensors", "snapshot", {});
  if (!snap.ok) return snap;

  const prox = snap.result.proximity;
  const light = snap.result.light;
  const accel = snap.result.accelerometer;

  const lux = light.available && light.values.length ? light.values[0] : null;
  const dist = prox.available && prox.values.length ? prox.values[0] : null;
  const xyz = accel.available && accel.values.length === 3 ? accel.values : [0, 0, 0];
  const gForce = Math.sqrt(xyz[0] * xyz[0] + xyz[1] * xyz[1] + xyz[2] * xyz[2]);

  if (lux !== null && lux < 15) {
    setVolumePercent(extId, 30); // خفض الصوت تلقائيا في الغرف المظلمة
  }
  if (gForce > 15) {

    window.InstaLink.browser.toast("تم اكتشاف هزة قوية للهاتف!");
  }
  return { lux: lux, proximity: dist, gForce: Number(gForce.toFixed(2)) };
}

1. Full C++ Adapter Example (native/adapter.cpp)

Every JSON string returned by describe() or invoke() must be heap-allocated (e.g., malloc/memcpy) so the InstaLink host can safely free it via instalink_extension_free_string().

#include "instalink_extension_api.h"
#include <cstdlib>
#include <cstring>
#include <string>

static std::string g_runtime_root;

static const char* DupJson(const std::string& s) {
    char* buf = static_cast<char*>(std::malloc(s.size() + 1));
    if (buf) std::memcpy(buf, s.c_str(), s.size() + 1);
    return buf;
}

Implement instalink_extension_game_attach_surface, resize_surface, detach_surface, and handle_input. Inputs arrive as JSON payloads for pointer, key, and virtual_button events:

C++ 60 FPS Render Loop Pattern

#include <android/native_window.h>
#include "instalink_extension_api.h"

static ANativeWindow* g_window = nullptr;

extern "C" INSTALINK_EXTENSION_EXPORT void instalink_extension_game_attach_surface(void* native_window, int width, int height) {
    g_window = static_cast<ANativeWindow*>(native_window);
    ANativeWindow_acquire(g_window);
    ANativeWindow_setBuffersGeometry(g_window, width, height, WINDOW_FORMAT_RGBA_8888);
    // Lock & draw pixels with ANativeWindow_lock / ANativeWindow_unlockAndPost on your render thread
}

extern "C" INSTALINK_EXTENSION_EXPORT void instalink_extension_game_detach_surface() {
    if (g_window) { ANativeWindow_release(g_window); g_window = nullptr; }
}

Test, debug & publish

Testing Web UIs on Desktop Chrome

Include lib/instalink-sdk.js in your HTML so all window.InstaLink calls automatically switch to console-logged mocks when previewed in desktop Chrome.

Debugging with ADB Logcat

adb logcat -s InstaLinkNative InstaLinkExtension
  • InstaLinkNative — Logs from C++ adapter loading (dlopen/dlsym) and native execution.
  • InstaLinkExtension — Logs extension permissions, capability calls, and all WebView JS console.log() / errors.

Packaging & pre-publish checklist

# Windows
tools\pack-extension.bat .\my-extension
# Linux / macOS
./tools/pack-extension.sh ./my-extension
  • Confirm manifest.json sits directly at the archive root (excludes native/, build/, dist/, .git/).
  • Sideload via InstaLink / Extensions / Install from file on Android before publishing.
  • For native extensions, verify runtime_bundle/adapters/<abi>/<library_name> is present inside the archive.
  • Prepare extension icon, screenshots, accurate version, and description matching manifest.json for store submission.
